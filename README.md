# Linux CLI Basics 🐧

**Platform:** TryHackMe  
**Status:** Completed ✅

## What I learned

I completed the Linux CLI Basics room on TryHackMe.

I practiced using the Linux terminal and learned how to:

- Move around different directories
- Create, remove and manage files
- Read files from the terminal
- Search for files
- Use basic Linux commands
- Work with file permissions
- Get information about the system

## What I found useful

The room gave me more practice with the Linux terminal. I learned
that a lot of things can be done directly from the command line
instead of using a graphical interface.

This is useful for cybersecurity because Linux and the command line
are used a lot when working with security tools and machines.
